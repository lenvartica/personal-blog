# Generation of Faith Ministries Website

A professional, responsive website for Generation of Faith Ministries – Nchoroiboro, Buuri District, Meru County, Kenya.

## Features

✨ **Modern Design**
- Responsive layout that works on all devices (mobile, tablet, desktop)
- Clean and professional color scheme
- Smooth animations and transitions

🎯 **Sections**
- **Navigation Bar** - Fixed navigation with mobile hamburger menu
- **Hero Section** - Welcome banner with church mission statement
- **About Us** - Vision and mission information
- **Core Values** - 8 core values with icons
- **Services** - 6 main ministry services
- **Leadership** - Pastor profiles
- **Contact** - Contact form, location, phone, and email
- **Footer** - Social media links, quick links, and service times

📱 **Mobile Responsive**
- Fully responsive design
- Mobile hamburger menu
- Optimized for all screen sizes

🎨 **Customization**
- Easy to customize colors, fonts, and content
- CSS variables for easy theme changes
- Well-organized and commented code

## How to Use

1. **Clone or Download** the files
2. **Open `index.html`** in your web browser
3. **Customize** the content with your church information:
   - Update pastor names and descriptions
   - Change contact information
   - Modify service times
   - Update social media links

## Customization Guide

### Change Colors
Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #1a472a;      /* Main green color */
    --secondary-color: #e8b44f;    /* Gold accent color */
    --accent-color: #d4a574;       /* Light gold */
}
```

### Update Contact Information
Find and update these in `index.html`:
- Phone number: `+254712345678`
- Email: `info@generationoffaith.ke`
- Location details
- Service times

### Add Social Media Links
Update the social media URLs in the footer section:

```html
<a href="https://facebook.com/generationoffaith"><i class="fab fa-facebook"></i></a>
```

## Deployment

To deploy this website:

1. **GitHub Pages** (Free)
   - Push to GitHub repository
   - Enable GitHub Pages in settings
   - Site will be live at `https://yourusername.github.io/repository-name`

2. **Web Host**
   - Upload files via FTP to your web host
   - Ensure `index.html` is in the root directory

3. **Domain Name**
   - Purchase a domain (e.g., generationoffaith.ke)
   - Point domain to your hosting
